# AI 产品经理投递参考

AgentLoopGate 适合展示 Agent 评测设计、发布决策和风险治理能力。它是研究型原型，当前没有真实客户采用、线上收益或正向自进化的证据。

## 简历项目描述

> **AgentLoopGate｜Agent 评测与发布治理原型**
>
> 针对 Agent 修改后总成功数持平、单项能力却可能退化的问题，设计基线与候选在同一任务集上的配对评测，结合证据完整性、任务回归、成本和延迟提出发布建议。Banking R15 完成 125 个预发布评测位置；在 15 个 Selection 任务上，基线与三个候选分别成功 6、6、5、6 个，三个候选均丢失基线已成功的两个任务，按冻结规则全部 HOLD。该结果说明配对检查识别了总分背后的任务得失，不代表线上收益或稳定提升。

## 面试时说明

- **目标用户与问题：** Agent 发布负责人需要判断一次修改是否值得继续评测，而总成功数可能掩盖已成功任务的退化。
- **关键产品决策：** 冻结评测任务和规则，逐任务对比基线与候选；证据不足、保护性规则不满足或成本不可接受时，停止推进。
- **结果的边界：** Selection 阶段每个版本在每个任务上运行一次；15 个任务的观察不能证明长期稳定性，也不能推导到其他业务。三个候选均未进入 Release 或上线。
- **下一步：** 用新的冻结实验开展重复试验，并邀请目标用户验证接入成本、误拦截及决策信息是否有用。
