# Standing private-experiment mandate

Effective 2026-08-23, the Owner granted the project operator a standing mandate
to run the private experiments required to reach AgentLoopGate's frozen research
objective. The operator does not need a new conversational approval for each
batch, retry-bounded successor, external-Updater call, or conditional
Release-ID/OOD/Replay evaluation.

This mandate changes the human-interaction cadence, not the evidence standard.
Every formal experiment must still:

1. freeze a new content-addressed Objective, Protocol, Study, execution source,
   Evaluation Baseline, pricing table, task positions, retry policy, and cost
   scope before paid work;
2. create and verify the exact machine authorization artifact required by the
   runtime before the applicable paid stage;
3. record Agent, User, and Updater calls, tokens, prices, cost, retries,
   timeouts, wall-clock duration, execution path, Trace and Lineage, including
   failed and unretained attempts;
4. stop and seal `HOLD` on missing denominators, unresolved evidence, or a
   failed hard Gate; and
5. never rerun, supplement, or extend a sealed formal identity.

The operator may create the machine authorization artifact as the Owner's
delegated research operator after verifying the frozen scope. The artifact is
an auditable capability bound to that exact identity; it is not a substitute
for freezing, nor permission to change the experiment after execution starts.

This standing mandate does **not** authorize Snapshot Promote, deployment,
changing repository visibility, publishing a GitHub Release, public release of
evidence, or paper/report submission. Those external or irreversible actions
continue to require a separate Owner instruction.

The mandate supersedes older project text that required a fresh conversational
Owner confirmation before every paid scope. Historical authorization evidence
and the boundaries under which earlier experiments ran remain immutable.
