# Changelog

All notable changes to AgentLoopGate will be documented in this file. The
project follows semantic versioning after its first public Release.

## 0.1.0 - 2026-08-29

### Added

- Evidence-governed Objective, Snapshot, Candidate, evaluation, Gate, Decision,
  and rollback contracts.
- DeepSeek Harness native Bundle integration that coexists with host Trace,
  JSONL/SQLite persistence, and OpenTelemetry.
- Frozen Banking reference-validation design with append-only task-attempt,
  model-usage, cost, retry, latency, and lineage evidence.
- Deterministic public demo, sanitized formal-result package tooling, and
  independent public-package verification.
- Contributor, security, conduct, and citation guidance for the first public
  source release.

### Changed

- Selection is bound to the same-pool A0 baseline and may terminate normally as
  `HOLD/ABSTAIN` when strict gain and non-regression gates are not met.
- Cost authority uses direct final task-attempt Agent and User model-call
  lineage with whole-attempt disclosure.

### Fixed

- Infra Invalid retained simulations can be sealed against their final failed
  task attempt without reclassifying them as valid results.
- Existing-only recovery can seal evidence after a runtime repair while new
  paid execution remains strictly runtime-bound.

This is the first public source release. No package-registry publication or
candidate deployment is implied.
